# 📊 Tableau HR Analytics Dashboard Project 🚀

**Unlock Workforce Insights with Interactive Dashboards**

This repository contains the Tableau workbooks and data for a comprehensive HR Analytics Dashboard project.  The dashboard is designed to empower HR managers with actionable insights through two distinct views: a **Summary View** for high-level overviews and an **Employee Records View** for detailed data exploration.

## 📖 User Story - HR Dashboard

**As an HR manager,**
**I want a comprehensive dashboard to analyze human resources data,**
**providing both summary views for high-level insights and detailed employee records for in-depth analysis.**

---

## 📊 Summary View

The **Summary View** provides a high-level overview of key HR metrics, divided into three sections:

### Overview

*   **Key Performance Indicators (KPIs):**
    *   Display the total number of **hired employees**.
    *   Display the total number of **active employees**.
    *   Display the total number of **terminated employees**.
*   **Trend Analysis:**
    *   Visualize the trend of **hired employees over the years**.
    *   Visualize the trend of **terminated employees over the years**.
*   **Categorical Breakdown:**
    *   Present a breakdown of **total employees by department**.
    *   Present a breakdown of **total employees by job titles**.
*   **Location Analysis:**
    *   Compare **total employees between Headquarters (HQ - New York)** and Branches.
    *   Show the **distribution of employees by city and state** on a map.

### Demographics

*   **Composition Analysis:**
    *   Present the **gender ratio** within the company using a pie chart.
    *   Visualize the **distribution of employees across age groups** (e.g., bar chart).
    *   Visualize the **distribution of employees across education levels** (e.g., bar chart).
*   **Correlation Analysis:**
    *   Present the **correlation between employee age groups and education levels** (e.g., heatmap).
    *   Present the **correlation between employee education levels and performance ratings** (e.g., heatmap).

### Income Analysis

*   **Salary Discrepancy Analysis:**
    *   Compare **average salaries across different education levels for both genders** (e.g., parabola chart) to identify potential discrepancies.
*   **Salary Correlation Analysis:**
    *   Present the **correlation between employee age and salary for each department** (e.g., scatter plot).

---

## 📝 Employee Records View

The **Employee Records View** provides a detailed, filterable list of all employees, enabling in-depth data exploration:

*   **Comprehensive Employee Listing:**
    *   Display a **tabular list of all employees** with key attributes:
        *   Name (Full Name)
        *   Department
        *   Position (Job Title)
        *   Gender
        *   Age
        *   Education Level
        *   Salary
*   **Interactive Filtering:**
    *   Enable users to **filter the employee list** dynamically based on **any column** (e.g., Department, Gender, Education Level, etc.) to facilitate targeted analysis.
